Sky City Guest House multi-page website starter


Pages
- index.html: Home
- rooms.html: Rooms and accommodation
- about.html: About the property
- gallery.html: Photo gallery with click-to-expand lightbox
- contact.html: Contact details and embedded map
- booking.html: Booking enquiry form that opens WhatsApp

Assets and scripts
- css/styles.css: shared mobile-first styles
- js/script.js: mobile navigation, gallery modal, WhatsApp enquiry handling

Open index.html in a browser or use Visual Studio Code with Live Server.\n
Important: Sample Unsplash photos are placeholders. Replace them with approved photos of the actual guest house. Confirm room categories, rates, amenities, and review information with the property before publication. The booking form is an enquiry, not a confirmed reservation.
